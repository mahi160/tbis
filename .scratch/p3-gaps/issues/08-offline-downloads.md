# 08 — Offline downloads

**What to build:** The user can download a Movie or Episodes to local disk and play them without the server; progress made offline syncs back when the server is reachable. Downloads are listed and removable, with a storage cap.

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] Download action on Movie and Episode (and "download season")
- [ ] Downloaded items play offline with tracks and subtitles
- [ ] Offline progress/played state syncs when back online
- [ ] Downloads list with sizes, remove action, and a storage cap
