# 02 — Movies page

**What to build:** The Movies tab shows a poster grid of every Movie from all Libraries merged, including watched ones. Each card has a 2:3 poster, the title, and the year, and watched Movies carry a small check badge. A sort dropdown offers Name (A–Z), Date added (newest first), Year (newest first), and Community rating (highest first). The grid stays smooth on libraries with thousands of Movies.

**Blocked by:** 01 — App shell, Login, and session

**Status:** ready-for-agent

- [ ] Movies from every Library appear in one grid
- [ ] Each sort option reorders the grid as described
- [ ] Watched Movies show the check badge
- [ ] A missing poster shows a placeholder
- [ ] Scrolling a large library stays smooth
