# 03 — Previous / next Episode in the Player

**What to build:** While an Episode plays, the Player offers previous and next Episode controls (buttons in the control bar plus keyboard shortcuts) that switch playback within the Series, reporting the current Episode's progress first. Hidden for Movies and at the Series' first/last Episode. If media keys (p1-gaps 04) have landed, previous/next track use the same actions.

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] Previous/next buttons and shortcuts switch Episodes, crossing season boundaries
- [ ] Controls hidden for Movies and disabled at the first/last Episode
- [ ] Current Episode's position is reported before switching; it is not marked played unless finished
- [ ] Remembered track picks and resume positions apply to the newly loaded Episode
